Cover Maker — a web app that turns your photos and a caption into multi-panel poster cover art in the style of GTA 6's covers, built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC. One hero panel plus three vignettes, each with its own photo, zoom and drag-to-pan; an editable title and subtitle in bold outlined poster lettering; three colour grades (Vice City Sunset, Neon Night, Pastel Day); one-click PNG export at 1080 x 1080, 1080 x 1350 or 1920 x 1080. It runs offline from its own static files and the photos never leave the machine. All lettering and art are its own — system fonts only, no Rockstar Games logo, artwork or font.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
